# External Clinics Maternity Survey

مشروع React + TypeScript + Vite + Tailwind لاستبيان رضا مرضى النسائية والتوليد لمستشفى إربد التخصصي.

## التشغيل محلياً

```bash
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## النشر على GitHub Pages

اسم الريبو المستخدم في الإعدادات:

```txt
ExternalClinisMaternitySurvey
```

```bash
npm run deploy
```
